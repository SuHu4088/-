# 文件移动工具

## 项目简介

该项目提供一个图形化界面的文件移动工具，可以将指定目录下的所有子文件夹中的文件移动到父文件夹中，并执行以下操作：

1. 支持文件的移动操作，包括检查重复文件并跳过相同文件。
2. 在移动文件时，会在终端输出正在移动的文件名称，并打印文件的 MD5 值进行比对。
3. 移动完成后，会自动删除空的子文件夹，并打印出包含文件的非空文件夹。

该工具使用了 `tkinter` 库提供图形界面，方便用户选择文件夹进行操作，提升用户体验。

## 版本信息

- **V1.py**：支持图形化界面，用户可以通过界面选择文件夹并移动其中的文件。
- **V2.py**：添加了在终端中打印移动的文件名称和文件夹的状态。完成移动后，扫描子文件夹并删除空文件夹。
- **V3.py**：新增了 MD5 比对功能，防止移动重复的文件，避免不必要的文件覆盖。

## 使用说明

### 1. 安装依赖

该工具依赖 Python 3 和 `tkinter` 库。您可以使用以下命令安装相关依赖：

```bash
pip install tk
```

### 2. 运行工具

打开终端或命令行，导航到该项目文件夹，运行 `V1.py`、`V2.py` 或 `V3.py`：

```bash
python V3.py
```

### 3. 使用图形界面

1. 程序启动后会弹出一个窗口，显示一个按钮 "选择文件夹"。
2. 点击该按钮，选择您想要操作的文件夹。该文件夹应包含多个子文件夹和文件。
3. 程序会自动扫描子文件夹中的文件，将它们移动到父文件夹中，并在终端输出移动过程中的信息。

### 4. 终端输出

- 在文件移动过程中，终端会显示以下信息：
    - 正在移动的文件名称。
    - 如果遇到重复文件，会打印文件的 MD5 值并跳过移动。
    - 移动完成后，会打印文件夹状态（是否删除空文件夹，是否存在非空文件夹）。
  
例如：

```
正在移动文件：example.txt
文件 example.txt 的MD5值：d41d8cd98f00b204e9800998ecf8427e
目标文件 /path/to/parent/example.txt 的MD5值：d41d8cd98f00b204e9800998ecf8427e
文件 example.txt 与目标文件相同，跳过并删除。
删除空白文件夹：/path/to/parent/subfolder1
非空白文件夹：/path/to/parent/subfolder2 中的文件：
file1.txt
file2.txt
```

### 5. 完成后处理

- 文件移动完成后，空的子文件夹会自动删除。
- 如果子文件夹中还有文件，将会打印出这些文件的名称。

### 6. MD5 比对功能（V3.py）

- 在移动文件时，如果目标文件已经存在，将计算文件的 MD5 值并进行比对。
- 如果源文件和目标文件的 MD5 值相同，则跳过该文件的移动，并删除源文件。
  
例如：

```
文件 example.txt 的MD5值：d41d8cd98f00b204e9800998ecf8427e
目标文件 /path/to/parent/example.txt 的MD5值：d41d8cd98f00b204e9800998ecf8427e
文件 example.txt 与目标文件相同，跳过并删除。
```

## 注意事项

1. 在移动文件时，请确保目标文件夹路径正确，且目标文件夹有足够的权限来执行文件操作。
2. 在 V3 版本中，如果文件相同且 MD5 值一致，程序会跳过该文件，并将其删除。如果有大量重复文件，请谨慎操作。
